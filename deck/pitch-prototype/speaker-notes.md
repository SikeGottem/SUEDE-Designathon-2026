## Live handling

- If time slips, shorten the map narration and creation step. Do not cut What / Why / How or the receiver-controlled ending.
- If asked about any blank: the team refused to invent the number. It will be filled only if the completed study supports it cleanly.
- If asked “why not text, voice or a call?”: those remain valid controls. The matched-format test must determine whether an authored object changes impact, effort or comfort.
- If asked “who is this for?”: name the need-state first: people caught between an ordinary text and a disproportionate physical gesture. University students, long-distance connections, close friends and close family are included examples, not validated or exclusive segments.
- If asked “why an app?”: the digital form is being tested for the ease of messaging plus deliberate authorship and asynchronous receiving; superiority is not assumed.
- If asked about anti-doomscroll prompts: they were removed from the live pitch. Context-aware resurfacing remains an unbuilt, untested backlog idea that could undermine sincerity or feel surveillant.
