# Meeting transcripts

Chronicle copies every completed recording from the Designathon Discord server into this folder before its local AI distils the meeting. User-supplied local Designathon recordings can also be captured here. Each file preserves the complete transcript and capture metadata; speaker attribution is retained only when the audio supports it reliably.

These transcripts are indexed in `.wiki/wiki.db` and are available to project agents and `python3 wiki.py search`. They are evidence, not automatic decisions: any consequential claim or team decision still follows the review rules in `WIKI/JUDGING.md` and `AGENTS.md`.

Recordings from other Discord servers must never be copied here.
